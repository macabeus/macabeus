I build tools that help people turn ideas into working software. My work includes Figma integrations, code generation, and AI-powered app creation.

In my spare time, I build tools for retro game decompilation, organize [GambiConf](https://gambiconf.dev/) in Brazil, and share what I learn through talks and articles.

## 🧪&nbsp;&nbsp;&nbsp;Retro game decompilation

**Matching decompilation** means recovering source code that recompiles into the original binary, byte for byte. I'm exploring how far AI and automation can take it, and building open-source tools along the way:
